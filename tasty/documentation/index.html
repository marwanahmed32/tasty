Tasty Corner - Restaurant & Cafe HTML Template

Version 1.0 · Pure HTML5, CSS3 and a few lines of vanilla JavaScript. No jQuery, no Bootstrap, no build step.

1. Getting started

Unzip the package and open index.html in any browser. To publish, upload all files to your hosting (cPanel, Netlify, GitHub Pages, etc.) keeping the folder structure.

2. File structure

index.html Home · about.html · menu.html · contact.html
css/style.css all styles · js/main.js mobile menu + menu filter · images/ all images · documentation/ this file.

3. Colors & fonts

Open css/style.css. At the top, the :root block holds every color (--primary, --dark, --light, --alt, --text) and font. Change them once; the whole site updates.

4. Logo & navigation

The logo and menu are in the <header class="nav"> block at the top of every page. Edit the text "TastyCorner" and links in each page.

5. Images

The template ships with original vector illustrations (SVG) so it works out of the box. To use your own photos, put them in images/ and change the file name in the page, for example --img:url(images/hero.svg) to --img:url(images/my-photo.jpg). Recommended: hero 1920x1080, other images 1000x1000, JPG compressed under 300KB. Free licensed photo sources: unsplash.com, pexels.com, pixabay.com.

6. Editing the menu

Open menu.html. Each dish is one block:
<article class="item"><div class="head"><h3>Name</h3><span class="price">$5</span></div><p>Description</p></article>
Copy a block to add a dish, delete it to remove one. The home page has a short menu with filter tabs; data-cat must be coffee, food or dessert.

7. Reservation form

The form is front-end only. To receive submissions by email: create a free form at formspree.io, copy your endpoint and set action="https://formspree.io/f/YOUR_ID" on the form in contact.html and index.html.

8. Google Map

In Google Maps search your address, click Share → Embed a map, copy the src value and paste it into the <iframe class="map"> in contact.html.

9. Arabic / RTL

Change the first line of each page to <html lang="ar" dir="rtl"> and in the Google Fonts link use an Arabic font such as Cairo, then set --font-head and --font-body to it in style.css. The layout flips automatically.

10. SEO

Edit the <title> and meta description on each page.

11. Browser support

Chrome, Edge, Firefox, Safari (latest versions), fully responsive from 320px.
